# Pivot — Notient becomes a CLI

> Date: 2026-04-27. Branch: `beta-spec`. Last commit before pivot: `c69bead`.

## Decision

Kill the Obsidian plugin product surface. Rebuild Notient as a vault-pointed CLI that exposes the multi-agent substrate to other agents (Claude Code, Codex, Aider, scripts, humans).

## Why

The substrate is sound. After commit `c69bead` the cold-boot transcript is clean, dynamo streams reliably, the indexer awakens without UNIQUE-constraint crashes, and the agent swarm completes runs end-to-end. What is broken is the integration layer between that substrate and the Obsidian UI: tabbed sidebar buttons no longer respond, Vitals does not populate, Chat returns red-button on send, decoration dots are silent. Multiple sessions tried to verify this by hand and failed; the surface area is too large and the feedback loop too slow.

A CLI inverts the problem. Each command is end-to-end testable in seconds. JSON-by-default output is consumable by agents. Streaming NDJSON gives the same liveness Stream/Vitals were trying to deliver. Approvals become flags. Undo becomes a command. A Claude Code agent can shell out to `notient` more naturally than it can drive an Obsidian UI through MCP.

## What dies (the Obsidian surface)

Delete entirely:
- `src/main.ts` (the plugin entry)
- `src/adapters/obsidianFacade.ts` (replaced by `src/adapters/fsVault.ts`)
- `src/ui/**` (sidebar, settings, modals, decorations, dashboards, approvals UI, search UI, coAuthor UI, onboarding wizard)
- `src/styles.css` (Phosphor Garden)
- `manifest.json`
- The `obsidian` dep from `package.json`
- Phase 4 / 4.5 / 4.6 plans referencing UI surfaces; archive don't-delete

The reusable Obsidian-API-touching files above (relatedSection, nativeGraphBridge, conversationStore, vaultBootstrap) get rebound to the new `VaultAdapter` interface backed by the file system instead of `app.vault`.

## New product surface

Single binary `notient` built with Bun. JSON by default. NDJSON for streaming commands. `--pretty` for humans. All commands accept `--vault <path>` or `NOTIENT_VAULT`.

```
notient init <vault>            Initialize: create .notient/, write config, health-check substrate.
notient awaken [--batch N]      Index every note: chunks + embeddings + graph. Streams NDJSON.
notient reindex <glob>          Re-index a subset.
notient search <query>          Search pipeline. --mode quick|balanced|deep --filter k=v
notient chat <query>            Multi-turn agent loop. Streams NDJSON. --safe (default) / --yolo
notient vitals <notePath>       Freshness, health, connectivity, maturity.
notient stream                  Ranked feed of pending proposals.
notient apply <proposalId>      Apply a staging edge/node. --dry to preview.
notient propose <kind> ...      Manually create a staging proposal.
notient undo                    Undo most recent mutation. --steps N.
notient history                 Recent mutations from the history table.
notient export-canvas <id>      JSON Canvas .canvas file.
notient health                  Probe dynamo + ollama. Print model availability.
notient schema                  Emit JSON Schema of every command for agent introspection.
```

Errors → stderr, non-zero exit. Long-running → NDJSON event stream on stdout. `notient schema` makes the CLI self-describing for any agent that wants to drive it.

## Phase plan (the new session writes the detail)

- **Phase A — Scaffold + nuke.** Add `src/cli/`, add `src/adapters/fsVault.ts`, delete `src/main.ts` + `src/adapters/obsidianFacade.ts` + `src/ui/**` + `src/styles.css` + `manifest.json`, drop the `obsidian` dep, update `package.json` `bin`, refresh tsconfig + biome. Gates green.
- **Phase B — Core commands.** `init`, `awaken`, `search`, `vitals`, `health`. NDJSON streaming. Fixture-vault integration test.
- **Phase C — Chat + tools.** `chat` command runs the agent loop. Tools: `vault.search_notes`, `agents.contradiction_check`, `vault.read`, `vault.write` gated by `--safe` / `--yolo`.
- **Phase D — Apply + undo.** `apply`, `undo`, `history`, `stream`, `propose`.
- **Phase E — Polish.** `schema`, `export-canvas`, `--help` everywhere, README written for agentic consumers.

## Hard rules (carry forward)

- TypeScript strict.
- No `console.log` outside structured CLI emitter; debug helpers (`debugCoAuthor`, `debugChat`, etc.) stay for internal trace.
- No abbreviations: `context` not `ctx`, `error` not `err`, `message` not `msg`, `event` not `evt`, `index` not `idx`, `options` not `opts`.
- No `[noun] - [parenthetical clause]` dash-clause prose anywhere — code, comments, commit messages, docs, `--help` text.
- No emojis in source.
- One commit per logical step on `beta-spec`. No `git add -A`; stage by name.
- No tests deleted unless the contract being tested is itself removed. UI tests die with the UI; substrate tests stay.
