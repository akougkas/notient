## Release v0.1.0, 2026-09-17

The owner authorized version 0.1.0, the push of `main`, the tag `v0.1.0` and a GitHub Release. npm publication, plugin directory submission and website deployment were not authorized and were not performed.

Selection-scoped Obsidian workflows: four editor-selection commands (ask, brief, find connections, propose an edit) in the palette and the editor menu, each refusing with a notice when there is no selection or the note is unsaved. A pure module maps editor offsets to saved-file UTF-16 offsets across BOM, CRLF and frontmatter and binds the selection to the saved revision; unit tests cover the mapping, every refusal and the request shapes, and a daemon integration test proves the mapped range equals the daemon's bytes, that a range edit is only a preview, and that a later save is a `CONFLICT`. `brief.run` and `notes.correlate` gained an optional `focus` range that sets the existing excerpt anchor from the saved bytes; no new engine.

Real Obsidian 1.13.7 host pass on the shipping plugin bytes (details and measurements in the [release notes](../release-v0.1.0.md)): sidebar, all four selection commands with one bounded real-model call each (15.6 s, 69.0 s, 110.2 s), exact source navigation, an agent-requested and an `assistant:human`-requested change in Review with diff and apply, editor synchronization, dirty-buffer veto with its explanation, change history and undo, and unattended recovery from a daemon restart in 8.6 s. Installed files matched the ZIP payload byte for byte. Two defects surfaced only there: `Vault.read` drops a BOM, so the plugin's revision differed from the daemon's for such notes (fixed by reading raw bytes); and a superseded pairing keeps its fail-closed editor protection until revoked (intended, now documented). The disposable Obsidian had exited before the pass and was relaunched with its isolated profile; only the disposable vault was ever driven.

Public readiness: the full unpushed history and the tree were audited. No credential, token, authorization header or env file was found. Raw agent transcripts and review documents that quoted the owner's private vault were removed from the tracked tree and preserved in the ignored local planning directory. LAN addresses, Windows user paths, temporary evidence paths and private host and vault names in tracked files were replaced with neutral wording; two evaluation tools now take their endpoint from the environment. README rewritten with a real terminal capture, release and source installation, the data-boundary statement and honest limits; `CONTRIBUTING.md`, `SECURITY.md`, an issue template and package metadata added; the website page updated to the real release and still undeployed. Every documented `notient` command was run as written against a fresh temporary vault.
