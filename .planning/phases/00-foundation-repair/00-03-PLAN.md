<objective>
Replace REST API-based LLM providers with native TypeScript SDKs.

Purpose: The REST API approach has proven unreliable for debugging UI freeze issues. Native SDKs provide proper async handling, better error messages, and eliminate HTTP overhead.

Output: Working LLM providers using `@lmstudio/sdk` and `ollama` JS SDK. Quick Actions complete without UI freeze.
</objective>

<context>
**Blocker:** UAT-003 - UI freezes after Quick Action triggers agent. LLM returns valid JSON, but something after causes freeze.

**Decision:** After 8 rounds of debugging REST API, migrate to native SDKs.

**Server Endpoints:**
- LM Studio: `192.168.86.249:1234`
- Ollama: `192.168.86.249:11434`

**Current Files to Replace:**
- `src/core/llm/providers/openai-compatible.ts` (base class)
- `src/services/lmstudio.ts` (LM Studio service)
- `src/services/ollama.ts` (Ollama service)

**Context7 Library IDs:**
- LM Studio: `/websites/lmstudio_ai_developer`
- Ollama: `/ollama/ollama-js`
</context>
