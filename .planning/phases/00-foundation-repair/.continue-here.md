## Decision: SDK Migration

After 8 rounds of architecture discussion, decision is to abandon REST API approach and migrate to native SDKs:

1. `@lmstudio/sdk` for LM Studio
2. `ollama` JS SDK for Ollama

Rationale: REST API debugging is a black hole. Native SDKs provide proper async handling, better error messages, and eliminate HTTP overhead guesswork.
