<context>
**The 2-day bug explained:**
ContextualActionDef interface had `agentType: "note-editor" | ...` but NO `type` field.
The onClick handler checked `if (action.type === "agent")` - always false because
`action.type` was undefined. So it always fell through to `sendToChat()`.

sendToChat → prefillChatAndSwitch → TaskQueue.enqueue (no taskType) → ChiefOfStaff
routes to "chat" → ChatAgent.execute() → per-chunk regex on full response string +
progress event per chunk → 500 events per response → UI freeze + CPU spin.

**Solution:** Delete ChatAgent. Chat UI uses ChatService.chat() directly (no agents).
All Quick Actions use triggerAgent() which goes to TaskQueue with explicit taskType.
</context>
