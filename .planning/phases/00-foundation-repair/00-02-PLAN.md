       - Ensure LM Studio is running with a thinking model loaded (e.g., falcon-h1r, qwen3)

    2. **Load Test (3-second target):**
       - Open Obsidian with the test vault
       - Cmd/Ctrl+P → "Reload app without saving" (or restart Obsidian)
       - Time from "Loading plugins" to sidebar appearing
       - **PASS:** <3 seconds, **FAIL:** >3 seconds or frozen

    3. **CPU Test (20% idle target):**
       - Let plugin sit idle for 30 seconds
       - Check Activity Monitor / Task Manager
       - **PASS:** <20% CPU, **FAIL:** >20% sustained

    4. **Chat Test:**
       - Open Notient sidebar → Chat tab
       - Send: "Hello, can you hear me?"
       - **PASS:** Get coherent response, **FAIL:** Error, empty, or no response

    5. **Search Test (2-second target):**
       - In Chat, send: "Find notes about [topic in your vault]"
       - **PASS:** Results appear <2s, **FAIL:** Timeout, error, or >2s

    6. **Console Check:**
       - Open Developer Tools (Cmd+Option+I / Ctrl+Shift+I)
       - Check Console tab for errors
       - **PASS:** No "JSON parse error", no repeated "no JSON found"
       - **FAIL:** Red errors related to JSON or LLM parsing

    7. **Agent Test:**
       - Click any Quick Action (e.g., "Enhance" on a note)
       - **PASS:** Agent runs and produces output
       - **FAIL:** Empty result, error, or no activity
