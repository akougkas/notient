## This Session - MAJOR BREAKTHROUGH

### Infinite Loop Bug FIXED
- **Root cause**: `taskQueue.ts:processNext()` had `queueMicrotask(() => this.processNext())` in finally block
- **Problem**: Ran unconditionally even when queue empty → infinite loop → CPU spike → UI freeze
- **Fix**: Created `scheduleNextIfQueued()` that only schedules when `tasks.some(t => t.status === "queued")`
- **Commit**: eff6f21
